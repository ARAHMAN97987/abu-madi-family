# آل أبو ماضي / الماضي

موقع تعريفي يوثق تاريخ عائلة أبو ماضي / الماضي الفلسطينية من الطنطورة وإجزم، قضاء حيفا.

## البنية

- `index.html` الصفحة الرئيسية بتسعة أقسام، وتدرج الوثيقة المختصرة كاملة.
- `expanded.html` النسخة البحثية الموسعة مع الجداول والمصادر الكاملة.
- `about.html` عن المشروع.
- `contact.html` نموذج التواصل.
- `404.html` صفحة الخطأ.
- `assets/styles.css` أنماط التصميم ونظام المتغيرات.
- `assets/app.js` تفاعلات التنقل، الـ lightbox، نموذج التواصل.
- `assets/images/` الصور والفيديو التعريفي.
- `sitemap.xml` خريطة الموقع لمحركات البحث.
- `robots.txt` إعدادات الزحف.

## التشغيل المحلي

```bash
cd site
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## النشر

الموقع ملفات ثابتة (static) تعمل على أي استضافة مجانية:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## نموذج التواصل

يستخدم Formspree. لتفعيله:

1. سجّل حسابًا مجانيًا على formspree.io.
2. أنشئ نموذجًا جديدًا واحصل على معرّفه.
3. استبدل `REPLACE_WITH_FORMSPREE_ID` في `index.html` و `contact.html` بمعرّف النموذج.

## المحتوى

- النسخة المختصرة والموسعة من وثيقة العائلة محفوظتان حرفيًا كما وردتا في المصادر الأصلية.
- الأسماء، التواريخ، والأرقام لم تُعدّل.
